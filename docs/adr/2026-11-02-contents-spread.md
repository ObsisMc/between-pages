# 「目录」是书里完整的一页跨页，翻到它时当前页保持原样

- 状态：已采纳
- 日期：2026-11-02
- 决策者：Ray
- 范围：领域
- 关联：取代 book-frontend-workspace 的D2 目录呈现；依赖 opening-book-home；依赖 book-surface

书签打开的「目录」不再是浮在页面上的对话框，而是这本书翻到的一个完整跨页：和其他书页同一个书本表面、同一位置、同一大小，看不到它下面的页面。地址不变，打开时在浏览器历史里加一条带 `contents` 的记录；当前页面不卸载，只被隐藏并设为 `inert`，所以合上目录后输入到一半的文字、滚动位置和编辑器状态都还在。返回、Escape、「合上目录」和书签都合上它，目录项替换这条记录，所以从目的地返回会回到打开目录的那一页。目录列哪些项沿用 book-frontend-workspace D2；本 ADR 只取代其中目录作为浮层的呈现，并决定版式、焦点和返回。

## 背景与问题

book-frontend-workspace D2 把目录定为「导航层」，实现是一个模态对话框：半透明遮罩、焦点陷阱、点书外关闭。Ray 在 2026-11-02 决定目录不要弹窗，要是一整个书页（[桌面稿](../design/2026-10-31-visual-exploration/images/39.webp)、[窄页稿](../design/2026-10-31-visual-exploration/images/40.webp)）。目录从任何页面打开，包括正在写的日记、填到一半的心愿表单和停在某处的日记列表；现有行为保证返回能关掉目录、从目录去的页面返回会回到原页面，这些要保留。

## 决策依据

1. 目录看起来是书的一页，不是叠在书上的弹窗（Ray 2026-11-02）。
2. 打开再合上目录不能丢掉当前页的未保存输入、滚动位置、编辑焦点或列表位置。
3. 返回、Escape 与书签的行为可预期，与现有一致：返回合上目录；从目录进入的页面返回到打开目录的页面（book-frontend-workspace D2）。
4. 键盘与读屏用户在目录打开时只遇到目录和书签，合上后回到书签。
5. 目录只列当前能进入的页面，不露日记文字或未揭晓的礼物（book-frontend-workspace D2、不变量 7）。
6. 窄窗口目录是一张单页，书签在屏内（opening-book-home D4）。

## 决策

### D1：目录是覆盖整个窗口的书页，原页面留在原处但隐藏

打开目录时，在原页面之上以固定定位铺满窗口，绘出 book-surface 的 `window` 书（窄窗口为纸面单页），和原页面的书重合在同一位置；没有遮罩，看不到下面的页面。原页面不卸载：外层加 `inert` 与 `visibility: hidden`，不绘制、不接收焦点和点击，滚动容器保持原位置，表单和编辑器保持状态。合上目录时去掉这两个属性，原页面原样出现。

目录的容器是 `<main aria-labelledby>`，标题「目录」为 `<h1>`；原页面隐藏时它的 `<main>` 不在辅助技术树中，所以同时只有一个可见的 main。不再是 `role="dialog"`，也没有自定义的焦点陷阱：原页面 `inert` 后，Tab 只在目录与书签之间移动。原因：依据 1、2、4。

### D2：地址不变，打开与合上走浏览器历史

| 操作 | 结果 |
| --- | --- |
| 点书签（目录未开） | 以同一地址、在历史状态里加 `contents: true` 推入一条记录 |
| 返回、Escape、「合上目录」、再点书签 | 后退一条，回到原页面，焦点回到书签 |
| 点目录项 | 以目的地替换目录这条记录；从目的地返回到打开目录的那一页 |
| 点原页面对应的目录项（标为当前页） | 只合上目录，等同返回，不重新载入原页面 |
| 刷新或从历史前进到目录记录 | 目录照常显示，原页面在其下按自己的地址载入 |

不新增 `/contents` 路由。依据 3 要求从目的地返回原页面，现在的历史结构已经满足，且原页面不重新挂载就不会丢状态（依据 2）。点书外关闭随遮罩一起去掉：目录本身就是整页。原因：依据 2、3。

### D3：桌面双页、窄窗口单页的版式

| 位置 | 内容 |
| --- | --- |
| 左页 | 「← 返回序言」（`/`）、标题「目录」、「日记」组、「管理」组 |
| 右页 | 「一起」组；没有「一起」时「管理」组移到右页；右下角「合上目录」 |
| 页脚 | 左页 01、右页 02 的页码（装饰，对辅助技术隐藏） |
| 窄窗口 | 一张单页：返回序言、目录、日记、一起、管理、合上目录 |

组标题前是一对小角色，日记与一起组的目录项有两位编号（跨组连续），管理组的目录项用图标；目录项有点线引导和箭头，最小高度 3.25rem。当前页（打开目录的那一页）的目录项带 `aria-current="page"` 和下划线。目录项的未读点沿用 `<EntryDot>`。原因：依据 1、5、6。

### D4：目录项与数据读取不变

每种关系状态下列哪些项，沿用 book-frontend-workspace D2 与现有实现：

| 账号 | 日记 | 一起 | 管理 |
| --- | --- | --- | --- |
| 从未绑定 | 今天的日记、所有日记 | — | 备份 |
| 绑定中 | 今天的日记、所有日记 | 两地时间、心愿与礼物、纪念日 | 双人空间、备份 |
| 已解绑 | 今天的日记、所有日记 | 心愿与礼物、纪念日（只读） | 双人空间（原空间）、备份 |

目录的数据（关系、各功能未读数）仍只在目录打开时读取，书签本身没有圆点。见面计划等以后的功能实现后加入「一起」组。原因：依据 5。

## 不变量

1. 打开再合上目录后，原页面的未保存输入、滚动位置和编辑器内容不变，焦点回到书签。
2. 返回、Escape、「合上目录」和书签都合上目录；从目录进入的页面返回到打开目录的那一页。
3. 目录打开时，原页面不可见、不可聚焦、不可点击；目录不是对话框，Tab 只经过目录与书签。
4. 目录只列当前账号能进入的页面，不显示日记文字或未揭晓礼物的任何信息。
5. 窄窗口的目录是一张无横向滚动的单页，书签完整位于窗口内。

## 备选方案

| 方案 | 优势 | 否决理由 |
| --- | --- | --- |
| **独立路由 `/contents`，原页面卸载** | 真正的一页，可直接链接到目录；不用同时保留两页的 DOM | 合上目录要重新挂载原页面：填到一半的表单丢失，日记列表重新加载并跳动，WebKit 还要再画一遍整页（依据 2）；从目的地返回要绕过目录记录，历史结构更复杂（依据 3） |
| **保留对话框，只换成书本外观** | 改动最小，现有测试几乎不变 | 仍是叠在页面上的弹窗、有遮罩和焦点陷阱，不是 Ray 要的书页（依据 1） |
| **翻页动画切到目录** | 最像真书 | 动画在 WebKit 的慢帧下会更卡；本轮不做动效（book-surface 依据 6） |

## 风险与代价

- 目录打开时原页面仍在内存中，日记的同步连接和列表的定时刷新照常运行；这与对话框时相同。
- 原页面隐藏期间，日记列表不会把被隐藏的文字算作已读：已读追踪要求页面可见、文字在可见区域内，`visibility: hidden` 的元素按不可见处理，需在测试中确认。
- 浏览器在目录与原页面切换时要合成两套书本表面；慢帧按 book-surface 记录，不优化。

## 落地顺序

1. 在 `src/book` 把 `ContentsBookmark` 从对话框改为 D1 的覆盖书页：去掉遮罩、`role="dialog"`、`aria-modal` 和焦点陷阱，给原页面外层加 `inert` 与隐藏；`ContentsPages` 按 D3 排版，用 book-surface 的书本表面。
2. 更新 `book.test.tsx`、`SiteContents.test.tsx` 与 `e2e/book.spec.ts`：保留返回、Escape、书签、目录项替换历史与几何检查，新增不变量 1、3 的检查，去掉焦点陷阱与点书外关闭的用例。
3. 与 book-surface 同一 PR 更新 `apps/web/README.md` 与验证记录。

## 验收标准

- 不变量 1：浏览器中在 `/days/:date` 写字、在 `/wishes` 填一半表单、在 `/days` 滚动右页后打开并合上目录，内容与位置不变，焦点在书签（`e2e/book.spec.ts`）。
- 不变量 2：组件测试与浏览器测试覆盖返回、Escape、合上目录、书签与目录项后的返回。
- 不变量 3：组件测试检查原页面 `inert`、目录无 `role="dialog"`；浏览器测试中 Tab 不进入原页面。
- 不变量 4：沿用 `SiteContents.test.tsx` 的三种关系状态。
- 不变量 5：浏览器在 375 与 320 宽下检查目录无横向滚动、书签在窗口内。
