# 主页的书本与纸张用 CSS/SVG，水彩插画用静态素材

- 状态：已采纳
- 日期：2026-11-02
- 决策者：Ray（确认书本、书脊和页边用 CSS/SVG，水彩插画使用图片；视觉效果待验收）
- 范围：技术栈
- 关联：依赖 opening-book-home；依赖 book-frontend-workspace

## 背景与问题

Ray 指出书本开篇实现只有近似排版，纸张、窗台和整体质感与已选原稿差异明显，要求在独立分支复现主页。原实现的注释记录过 WebKit 在两倍像素密度下绘制整页模糊阴影与渐变耗时约一秒，因此不能只增加实时绘制层来追求质感。

## 决策依据

1. 纸张、书脊、页边和窗台是装饰，不随时间与业务状态逐帧变化。
2. 真实文字与控件必须可选取、可访问、可操作，不能用整页截图代替产品。
3. 这次只验证主页，保留现有日记工作区与服务端边界，不新增依赖。

## 决策

### D1：静态装饰与实时内容分开

书本轮廓、层叠页边、书脊、阴影和纸面细纤维由 CSS 与内联 SVG 几何、渐变和 128px 可缓存的过程式 SVG 纹理绘制，不使用整本书或纸面位图，也不在整页运行模糊或噪声滤镜。水彩窗台使用本地透明 WebP 插画，未绑定时使用空的搭档窗台版本。日期、时钟、作息时间轴和入口保留为真实 HTML。宽窗口保留双页，窄窗口用单页向下延展，不拉长整本书的页边。

### D2：实现只作用于主页

样式限定于 `.home`，书签外观使用主页存在时的选择器。当前空间入口收在页脚，未绑定与解绑的邀请界面继续使用原组件。日记工作区与目录的业务行为不变。字体使用随项目提供的 Noto Serif SC 固定文案子集，其余字形沿用回退字体。

### D3：视觉还原与性能分别验收

不增加测试重试或等待来容忍昂贵渲染。用现有主页、时钟与目录组件测试和真实 PostgreSQL 的书页浏览器测试验证功能；另外在 Chromium、WebKit 的两倍像素密度下检查布局和目录响应。记录本机与网络条件，不把本机结果宣称为真实设备或弱网验收。

## 不变量

1. 主页无日记正文或摘要，未绑定不显示搭档时间与共同醒着时段。
2. 所有业务文字、时钟与交互均为真实 HTML，装饰图片不能成为功能入口。
3. 窄窗口不横向溢出，书签与插画保持在书页和视口内。

## 备选方案

| 方案 | 优势 | 否决理由 |
| --- | --- | --- |
| 所有插画也用实时 CSS/SVG 滤镜绘制 | 无位图 | 水彩窗台适合美术素材；整页滤镜存在已观察到的 WebKit 绘制成本 |
| 整本空白书用静态位图 | 纸面细节接近原稿 | Ray 明确选择书本、书脊和页边由 CSS/SVG 实现 |
| 将整张参考图作为主页 | 外观固定 | 数据与控件不能正常变化，也无法保留文字选择、可访问性与窄屏布局 |

## 风险与代价

生成插画只能近似参考，须由 Ray 确认。水彩 WebP 需要首次传输与解码；本机验证不能代表跨国网络与真实手机。主页采用参考的浅色纸面，不跟随系统深色主题。该分支是主页视觉试验，不代表其他页面已完成同样的视觉复现。

## 落地顺序

1. 在独立分支用 CSS/SVG 绘制书页、书脊和纸面纹理；制作水彩窗台素材，保留来源与提示词。
2. 复用现有主页数据和导航，限定样式作用域，检查桌面与窄窗口。
3. 运行相关组件测试、真实 PostgreSQL 浏览器测试、构建和静态检查，记录性能与限制；交 Ray 对照原稿验收。

## 验收标准

- 不变量 1 由既有 `HomePage.test.tsx`、`two-clocks.test.tsx` 与 `e2e/book.spec.ts` 验证。
- 不变量 2 通过浏览器实际操作、文字与链接检查，以及素材检查验证，不为静态样式编写镜像测试。
- 不变量 3 由 `e2e/book.spec.ts` 的 375px、320px 与桌面几何检查验证。
- 纸张、插画、字体与比例由 Ray 对照原稿确认；响应数据与未完成项记录在本次验证记录中。
