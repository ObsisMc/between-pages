# 开发路线

更新日期：2026-10-24。阶段 0 的技术可行性验证已完成，正式技术栈与开发规范待确认，其余产品阶段尚未完成。不设未经评估的交付时间。结果见[验证记录](./validation/collaboration-readiness-2026-10-24.md)。

## 阶段 0：协同核心验证

用最小双客户端原型验证字符级输入、不可变作者、作者级修改权限、个人撤销、中文输入法、Unicode、并发插入与断线重连。

服务端校验必须有效，不能仅靠编辑器拦截。记录稳定位置、本地待发送编辑和权威提交状态如何映射。

当前已通过已列明的协议与三引擎技术验证。进入阶段 1 前，按实现准备方案共同确定编辑器、协议内核、服务端运行方式和开发流程，写正式 ADR；实体设备验收保留在发布门槛。

## 阶段 1：正式项目与单篇日记

搭建选定的前后端运行环境、PG 迁移与本地开发入口，接入认证和双人空间。实现按当地日期创建、并发唯一、历史日记访问、字符归属与作者保护。

出口：有明确的启动说明、环境变量示例、数据库迁移，以及对应 AUTH/DATE/EDIT 验收证据。密钥与真实日记不进入仓库。

## 阶段 2：可靠协同与阅读

完成实时编辑光标、本地持久化、断线恢复、持久化确认、稳定阅读位置、跨设备同步和精确未读定位。补齐所有编辑入口的作者保护。

出口：通过 SYNC/SAVE/READ/TIME 的 P0 验收，重点确认没有旧全文覆盖、静默丢字或越权修改。

## 阶段 3：Google 可读副本与恢复

实现独立的 Drive 授权、事务 outbox、每日 Google Doc、版本化数据快照、失败重试与真实备份状态。验证远端修改保护和独立恢复。

出口：通过 GOOGLE 的 P0 验收，完成空环境恢复演练；授权的发布状态符合长期后台运行要求。

## 阶段 4：首版体验与发布

沿用已选的温暖、简约视觉方向，调整字体色、时间展示和交互。完成桌面及真实手机浏览器验证，检查长文和跨国网络延迟下的表现。

出口：全部 P0 验收有证据，P1 的实际结果与遗留问题明确记录；应用状态、备份状态与隐私权限说明准确。
