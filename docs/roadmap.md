# 开发路线

更新日期：2026-10-28。阶段 0 已完成，阶段 1 进行中，阶段 2 设计已采纳、未开始实现。不设未经评估的交付时间。每一项的实现细节见对应 ADR 和 PR；本文只记录阶段、范围和当前进度。

**本文是项目进度的唯一来源。** 完成或开始某一项的 PR，在同一个 PR 里更新对应行和上面的日期；根目录 README 的"当前状态"只保留一行概况，日期与这里一致。`verify-roadmap-current` 检查这两点，不影响进度的功能 PR 打 `roadmap-not-needed` 标签并说明原因。

## 已确认的范围

- 手机相关工作暂缓，当前只做桌面 Web（用户于 2026-10-24 确认）。实体手机、Expo/React Native、WebView 与原生存储桥接均后置；未来恢复手机支持时再安排验证，当前不宣称手机体验已经通过。
- 性能先达到日常写作无明显卡顿即可，深入优化后置（用户于 2026-10-24 确认）。快照、增量同步和历史压缩按实际需要引入；任何此类改动都必须保留作者保护、待发内容和持久化确认语义。
- 首版首次绑定后搭档固定，可停止协作、解绑及仅与原搭档恢复；不支持更换对象或误绑纠正（用户于 2026-10-26 确认）。待评估场景见[未来功能清单](./future-features.md)，不纳入首版实施范围或默认排期。

## 阶段 0：协同核心验证（已完成）

用最小双客户端原型验证了字符级输入、不可变作者、作者级修改权限、个人撤销、中文输入法、Unicode、并发插入与断线重连，服务端校验有效。结果见[验证记录](./validation/collaboration-readiness-2026-10-24.md)；正式技术栈与协同内核由 [ADR-0006](./adr/0006-formal-stack.md) 确定。实体设备验收保留在发布门槛。

## 阶段 3：Google 可读副本与恢复

实现独立的 Drive 授权、事务 outbox、每日 Google Doc、版本化数据快照、失败重试与真实备份状态。验证远端修改保护和独立恢复。

出口：通过 GOOGLE 的 P0 验收，完成空环境恢复演练；授权的发布状态符合长期后台运行要求。

## 阶段 4：首版体验与发布

沿用已选的温暖、简约视觉方向，调整字体色、时间展示和交互。当前先完成桌面 Web 验证，检查长文和跨国网络延迟下的表现；手机浏览器验证随手机支持恢复后另行安排。

邮件通知（用户于 2026-10-28 决定放在本阶段）：对方写了新内容而你一段时间内没读时发邮件提醒。依赖阶段 2 的列表未读判定（只计已成历史版本的文字，见[未读与日期页 ADR](./adr/2026-10-28-unread-and-day-page.md)）、阶段 3 的后台 worker（ADR-0006 第 20 条，与 Google 备份共用）以及部署（邮件中的链接与发信域名）。动手前另写 ADR，决定发哪些事件、频率、邮件里是否含日记原文与退订方式；通知与列表、未读执行同一隐私边界，不透露对方未共享的日记或阅读行为（SHARE-11）。

出口：全部 P0 验收有证据，P1 的实际结果与遗留问题明确记录；应用状态、备份状态与隐私权限说明准确。
