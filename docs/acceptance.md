# MVP 验收清单

日期：2026-10-24；产品级验收尚未完成。规格来源：[diary-spec.md](./diary-spec.md)。

协议、浏览器与 PG 层已有[独立验证记录](./validation/collaboration-readiness-2026-10-24.md)。以下清单仍保持未勾选：原型测试不替代正式认证、浏览器输入法、存储与界面的完整验收。

## 执行方式

P0 是首版发布阻断项；P1 是体验目标，未满足时需记录影响与后续处理，不得伪称通过。每条执行结果记录测试版本/commit、设备浏览器、网络条件、操作步骤、预期与实际、截图或测试输出。勾选仅表示附有证据的通过，不能因代码存在而勾选。

测试账号：A、B 属于同一空间，C 不属于该空间；A1/A2 为 A 的两个设备。测试数据使用虚构日记，不使用真实私密内容。默认初始正文：A“今天很累，但是想到你就开心了。”；B 在逗号后插入“抱抱！”。

自动化优先覆盖状态机、权限、数据库竞态、Unicode、同步与故障；真实手机输入法、阅读位置、颜色可读性和删除手感人工验收。测试只在隔离数据库、专用 Google 测试文件夹和测试账号执行。

## 登录与空间 AUTH

- [ ] AUTH-01 / P0：未登录不能请求日记、导出、备份状态或 WebSocket 订阅；C 即使知道 diaryId 也不能访问。
- [ ] AUTH-02 / P0：A 创建邀请、B 明确接受后加入；失效、撤销或重复使用的邀请不能再次加入。
- [ ] AUTH-03 / P0：B、C 并发争取最后一个名额，最多一人加入，总成员数不超过两人。
- [ ] AUTH-04 / P0：Google 登录成功但拒绝 Drive 授权，仍可编辑；Drive 备份明确显示未连接。
- [ ] AUTH-05 / P0：会话过期或访问被撤销后，HTTP 和协同连接均拒绝新写入；本地未同步文字保留为可恢复草稿。
- [ ] AUTH-06 / P0：同设备退出并切换账号，不能看到上一账号的本地日记/草稿；退出前存在未同步内容时有明确保留/恢复说明。

## 日期与创建 DATE

- [ ] DATE-01 / P0：给定服务端 UTC 时间 2026-10-24T02:00:00Z，A 时区 Asia/Shanghai 创建日期为 2026-10-24，B 时区 America/Los_Angeles 创建日期为 2026-10-23；不错误合并为同一天。
- [ ] DATE-02 / P0：同空间同日期存在日记时，重复点击写今天只打开原 diaryId；两个空间同日期不相互影响。
- [ ] DATE-03 / P0：让至少 20 个请求并发创建同空间同日期，数据库仅一行；其余返回可定位已有日记的结果，不出现孤立协同文档或错误覆盖。
- [ ] DATE-04 / P0：编辑旧日记、跨午夜继续写、改变设备时区及另一方打开，原 diaryDate 均不变。
- [ ] DATE-05 / P0：设备时钟故意偏移，今天仍由有效时区和服务端 UTC 推导；无效 IANA 时区被明确拒绝。
- [ ] DATE-06 / P0：历史日期可打开/补写，缺失的过去日期可明确创建；离线不伪称新日记已成功创建。

## 字符归属与编辑 EDIT

- [ ] EDIT-01 / P0：按示例穿插后，作者顺序是 A/B/A；过滤 A 后仍为“今天很累，但是想到你就开心了。”，过滤 B 后为“抱抱！”。
- [ ] EDIT-02 / P0：双方均可在另一方文字的任意可感知字符边界继续插入；每个新增字符（含空格、换行）归输入者。
- [ ] EDIT-03 / P0：A 删除/替换己方文字成功；不能修改 B 的文字；颜色或富文本属性操作不能伪造作者。
- [ ] EDIT-04 / P0：Backspace 遇到 B 时只跳到前方 A 文字末尾，本次不删字；Delete 对称；无己方文字时停在边界。
- [ ] EDIT-05 / P0：长按连续删除到作者边界后停止连删；松开再按才可删跳转后的己方文字；真实手机与桌面验证。
- [ ] EDIT-06 / P0：选区含 A/B 时删除、剪切、打字替换及粘贴替换均被阻止且正文不变；复制成功；纯己方选区可替换。
- [ ] EDIT-07 / P0：A 建立选区后 B 在该范围插入，再由 A 删除/替换；B 新增文字仍完整，A 不发生静默回滚或越权。
- [ ] EDIT-08 / P0：从外部富文本/伪造作者标记粘贴，得到纯文本且归当前用户；拖动文本不能绕过限制。
- [ ] EDIT-09 / P0：A 撤销自己的插入和删除，只影响 A；A 原文中已有 B 的后续插入仍保留；重做不伪造 B 的作者。
- [ ] EDIT-10 / P0：emoji 家庭组合、肤色、旗帜、组合音标、中英文混排，插入、选择、删除、同步与导出均不拆坏字符。
- [ ] EDIT-11 / P0：真实中文输入法确认前，拼音/候选字不发给 B；确认后只出现一次；远端更新不打断 composition。
- [ ] EDIT-12 / P0：绕过前端直接发送伪造 actor、修改作者、删除 B 字符或构造低层协同更新，服务端拒绝且数据库/其他客户端不受影响。
- [ ] EDIT-13 / P1：两种字体色正文清晰、没有永久作者底色；同一用户跨设备颜色一致；可借名字图例及点击识别作者；只读单方过滤可退出恢复完整正文。

## 协同与持久化 SYNC / SAVE

- [ ] SYNC-01 / P0：A/B 同时在同一位置连续输入不同句子，合法内容全部保留，不逐字破碎交错；最终正文、顺序及作者一致。
- [ ] SYNC-02 / P0：在不同位置并发输入、删除己方文字并接收对方插入，全部客户端最终收敛，作者保护成立。
- [ ] SYNC-03 / P0：显示对方名字、光标及选区；对方在上方插字后光标仍指向对应内容；光标移动不生成正文写入/未读/备份。
- [ ] SYNC-04 / P0：A1/A2 同账号并发编辑，不互相覆盖；B 的多个在线会话可辨别，不冒充独立作者。
- [ ] SYNC-05 / P0：断线、关闭页面或心跳过期后清除过期光标，不长期显示正在编辑。
- [ ] SYNC-06 / P1：阅读长文时，上方收到插入不抢焦点、不强制跳到对方光标，当前阅读内容保持稳定。
- [ ] SAVE-01 / P0：延迟服务端持久化期间本地输入立即可见，但不显示已保存到服务器；事务成功后才显示已保存。
- [ ] SAVE-02 / P0：A 离线续写已缓存日记，刷新/关闭重开后能恢复本机已持久化文字；重连与 B 的在线更新合并，不整篇覆盖。
- [ ] SAVE-03 / P0：模拟重复、丢失、乱序消息及 ACK 丢失，重试不重复插字，不因旧快照回退；比较恢复前后的完整正文及作者元数据。
- [ ] SAVE-04 / P0：服务端在“收请求后提交前”崩溃，不能提前确认/广播为已提交；重试可恢复。提交后 ACK 前崩溃，重试只应用一次。
- [ ] SAVE-05 / P0：数据库失败或服务端重启，已确认文字重启后仍在；未确认文字保留本机且状态真实。
- [ ] SAVE-06 / P0：本地存储空间不足、禁用或写入失败时，明确提示并保留当前正文可复制/下载，不误报已保存到本机。
- [ ] SAVE-07 / P0：服务端拒绝过期/非法操作时，待发送内容保留在恢复草稿，不静默消失，也不让其他成员看到未接受的非法状态。
- [ ] SAVE-08 / P0：连续进行“输入→收到远端更新→断线→重连→刷新”，不出现合法输入先显示、稍后被旧全文全部回退的情况。

## 未读与时间 READ / TIME

- [ ] READ-01 / P0：B 在昨天和更早日记中间插入，A 能看到有新内容，并跳到准确位置；A 自己输入不产生自身未读。
- [ ] READ-02 / P0：A 打开长日记但未滚到下方，下方新内容仍未读；后台标签页和不可见区域不自动算已读。
- [ ] READ-03 / P0：A 先看到较晚写入的内容，未看到的较早写入仍未读；不能用最大操作序号误清除。
- [ ] READ-04 / P0：阅读标记跨设备合并；重复更新、光标、导出不产生未读；已删除文字不导致无法完成的未读定位。
- [ ] READ-05 / P0：双方互相看不到对方的阅读回执，不存在默认公开的已读时间。
- [ ] TIME-01 / P0：数据库时间为 UTC 时间点；同一文字在上海、洛杉矶正确推导当地时间，包含美国夏令时切换前后两个不同 UTC 时间对应的重复当地小时。
- [ ] TIME-02 / P0：离线输入重连后仍保留原客户端写入时间及服务端接收时间；设备时钟异常不改变协同排序、日期或权限。
- [ ] TIME-03 / P0：相邻同作者但不同时间批次不会因压缩丢失时间；替换的新文字记录新写入时间，点击可查看。

## Google 可读副本与恢复 GOOGLE

- [ ] GOOGLE-01 / P0：授权请求只包含实际所需权限；state 等校验有效；令牌不出现在浏览器持久化、日志或数据导出中。
- [ ] GOOGLE-02 / P0：关闭应用页面后后台仍可备份；撤销/过期时显示需重新连接，不影响 PG 保存；重新授权可续传积压任务。
- [ ] GOOGLE-03 / P0：手动导出及自动导出均生成可读 Doc，日期、换行、Unicode、作者图例、双方字体颜色及穿插顺序正确；重复请求复用同一映射。
- [ ] GOOGLE-04 / P0：只有目标 Google 账号和明确分享的人能访问，退出应用仍能从 Drive 打开；没有默认公开链接或未经操作发送的邀请。
- [ ] GOOGLE-05 / P0：PG 正文提交和 outbox 同成败；任务进程重启后可续跑；重复任务、版本倒序、并发重试不让旧版本覆盖新版本或生成重复有效副本。
- [ ] GOOGLE-06 / P0：Google 限流、网络失败、权限撤销、存储空间不足时重试/提示正确；始终区分已存 PG 与已备份，显示真实完成版本和时间。
- [ ] GOOGLE-07 / P0：Doc 已更新但 JSON 上传失败，以及相反情况，不能宣称该版本备份完整；重试最终补齐同一目标版本。
- [ ] GOOGLE-08 / P0：在 Google 直接改文档，后续导出不静默覆盖；包含检查后到写入前发生修改的竞态；文件被删时不自动抹去历史或反复新建。
- [ ] GOOGLE-09 / P0：应用误写空内容或删除后，至少一份此前历史数据快照仍可用；取消 Google 连接不删除既有文件。
- [ ] GOOGLE-10 / P0：从独立备份在空数据库恢复，正文、顺序、作者、日期、UTC 时间及读取进度一致；双方可继续协同，且作者限制仍有效；重新授权恢复备份能力。
- [ ] GOOGLE-11 / P0：快照 schemaVersion/校验失败被明确拒绝；导出不含会话和 OAuth 凭据；完整数据库备份有独立恢复记录。
- [ ] GOOGLE-12 / P1：服务健康且无积压时，目标版本约 60 秒内完成 Google 两类备份；记录样本及实际延迟，不把该目标标为无条件保证。
