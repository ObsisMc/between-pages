# 协同核心验证记录（第一轮历史）

本文件保留第一轮原型的历史结果。后续补齐的浏览器、IndexedDB、光标与性能验证见[最终报告](./collaboration-readiness-2026-10-24.md)；下文的“未完成”描述对应第一轮时点。

日期：2026-10-24（北京时间）。分支：`codex/collaboration-core-validation`。

## 结论

受约束操作 + 服务端作者校验 + 稳定字符标识 + 本地待发送日志的路径，在本轮协议与数据库场景中成立。没有采用全文覆盖同步；客户端不以服务器旧快照替换本地待发送内容。

28 项核心测试、9 项真实 PostgreSQL 集成测试通过，无失败或跳过。其中 2 项 PG 测试实际强制杀死独立服务子进程，分别覆盖事务提交前后。完整产品的浏览器与端到端验收未完成。

## 环境与运行

- Node.js v24.20.0，Node 内置测试运行器；pg 驱动版本锁定在 package-lock.json。
- Docker PostgreSQL 18.6，镜像 postgres:18-alpine；本轮拉取 digest 为 `sha256:898c60cb390d1085bc97bdd6a1ae968757421df394b071848b52b1c09c89d6a5`。
- 测试数据为 A/B/C 虚构账号和文本。PG 仅绑定本机临时端口，不连接真实日记库。
- `npm test`：28/28 通过。核心套件约 19 秒，主要耗时来自随机调度和全日志重建；不是性能基准。
- `npm run test:pg:docker`：9/9 通过，脚本自动创建并清理独立 PG 容器。

## 场景与观察

| 重点 | 故障或操作 | 观察结果 |
| --- | --- | --- |
| 不改对方文字 | B 直接提交删除或替换 A 字符，绕开客户端保护 | 整个操作拒绝，正文和 outbox 不变 |
| 不伪造作者 | 在载荷中加 actor/authorId/seq/二进制更新 | 严格 schema 拒绝；HTTP 以服务端会话映射确定 actor |
| 操作幂等 | 相同操作重试、20 个跨实例并发重试 | 只产生一条操作和一条 outbox；相同 ID 改载荷或换作者拒绝 |
| 并发输入 | A/B 同位置插入连续句子；A 的两个设备同时写 | 连续输入块保留，客户端最终内容、作者和顺序一致 |
| 旧快照 | 本机离线继续写，收到旧读和对方的新读 | pending 不清空，己方新增文字仍在，最终合并 |
| 乱序/依赖 | 完整记录倒序，或只到达缺少前序的记录 | 完整日志重排；稀疏缺口不部分应用，可全量重试 |
| 丢 ACK | PG 已提交但客户端没有确认 | pending 保留；新服务读出相同操作后清除 pending，不重复插字 |
| 提交前故障 | SQL 已写入后注入失败或 SIGKILL 服务进程 | 事务回滚；正文版本、操作、outbox 同时保持未提交，可重试 |
| 提交后故障 | COMMIT 后、返回确认前 SIGKILL 服务进程 | 操作、版本和任务保留；重连找到原记录，不重复写入 |
| 本机恢复 | 文件同步落盘、原子替换后重新创建客户端 | pending 内容可恢复，并与对方更新合并 |
| 本地存储失败 | 持久化适配器报空间不足 | 当前输入仍在内存，状态明确为保存失败，可重试 |
| 本人删除与个人撤销 | B 在 A 原文内插入；A 撤销自己的原文 | B 内容仍保留；独立删除标签不被另一设备撤销误清除 |
| 旧选区 | A 的删除目标已确定，B 随后在其间插字 | 只删除明确指向的 A 字符，B 新增文字不受影响 |
| 原始锚点被删 | 离线插入锚点在服务器被删除 | 墓碑保留锚点，离线插入可以重连提交 |
| 拒绝待发操作 | 服务端策略拒绝本地编辑 | 保存为明确标记的恢复草稿，不伪称共享正文保存成功 |

## 随机验证

核心测试含 150 个固定种子，可复现：

- 100 个插入调度，每个 60 步，覆盖三个客户端、离线积压、旧读、同步及客户端重开。独立 oracle 记录所有生成字符 ID、正文和作者，最终逐项比对，不只比较客户端彼此一致。
- 50 个混合调度，每个 40 步，覆盖插入、己方删除、个人撤销/重做与同账号设备。独立可见性 oracle 比较应保留的字符，并逐项检查删除目标作者。

总计 8,000 个调度步骤。随机测试增加覆盖，不构成任意输入或网络状态下的数学证明。

## 验收映射与未完成范围

协议层覆盖 EDIT-01/03/07/09/12、SYNC-01/02/04、SAVE-01～08 的相关底层行为。SAVE-06 只验证注入的适配器写入失败；SAVE-02 只验证文件适配器恢复；不表示已验证浏览器站点存储。

以下仍未完成，不勾选产品级验收：

- 浏览器 beforeinput、真实中文输入法、系统剪切粘贴、删除跳转及跨操作形成的组合字符边界。
- IndexedDB、标签页并发、本地账号切换后的缓存隔离、手机后台回收。
- 实时 WebSocket 房间、光标、阅读位置、正式 Google 登录与空间绑定；HTTP 测试只用虚构会话映射。
- 未读、Google 备份上传、日记日期创建、生产部署和数据库主机崩溃/灾难恢复。本轮 outbox 只验证事务原子性。
- 大文档性能、墓碑压缩、增量传输、协议版本升级、恶意客户端资源消耗和更全面安全评估。

当前实现每次重建全文日志，实验性序列算法没有经过独立形式化验证。可以继续作为浏览器验证的后端基线；不能据此决定最终采用自研 CRDT 或直接上生产。
