# 共享页面手动验收

日期：2026-11-04 写好清单。**状态：未执行，由 Ray 在 PR #76～#79 合并前在开发环境执行。** 本文是[共享页面 ADR](../adr/2026-11-04-shared-pages.md)的手动验收，对应[验收清单](../acceptance.md)的 PAGE-01～05。

已由自动测试覆盖、这里不再重复的：第三人的所有接口与同步被拒、提交与解绑并发、取锁顺序、`wrote` 历史的增长、页面不写 `backup_outbox`、迁移保留现有日记。这里验的是人用起来的感受和界面。

## 准备

1. 切到分支 `claude/shared-pages-web`（包含 #76～#78），`npm ci`；没有 `.env` 时先 `cp .env.example .env`。
2. `npm run db:up`，然后 `npm run db:migrate`（迁移 `0011`、`0012`）。
3. `npm run dev:oidc`、`npm run dev:api`、`npm run dev:web` 各开一个终端。
4. 两个浏览器窗口（或两个 Chrome 配置），分别用"开发登录"登录 A、B；A 生成邀请，B 接受。
