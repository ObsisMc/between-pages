## 准备

1. 切到分支 `claude/shared-pages-web`（包含 #76～#78），`npm ci`；没有 `.env` 时先 `cp .env.example .env`。
2. `npm run db:up`，然后 `npm run db:migrate`（迁移 `0011`、`0012`）。
3. `npm run dev:oidc`、`npm run dev:api`、`npm run dev:web` 各开一个终端。
4. 两个浏览器窗口（或两个 Chrome 配置），分别用"开发登录"登录 A、B；A 生成邀请，B 接受。

## 用起来的感受

这几条没有对错，用一段时间后填，决定后续要不要做（[未来功能清单 F-10](../future-features.md#f-10共享页面的后续能力)）：

- 写清单时，不能改对方写的字够用吗？
- 页面多了以后，平铺列表还找得到吗？
- 有没有误删过？
- 打开就清除未读，有没有漏看新内容？
- 见面计划要不要照这样在页面里写，形式要不要调整？
