日期：2026-11-18 写好清单。**状态：Ray 于 2026-11-18 做了最小检查并通过（见下一节），隐私说明已核对；完整清单未走。** 本文是[日记之外的 Google 副本 ADR](../adr/2026-11-17-google-copy-beyond-diaries.md) 落地顺序第 3 步的人工走查，对应[验收清单](../acceptance.md)的 GOOGLE-13～18。

已由自动测试覆盖、这里不再重复的（真实 PG 加本地模拟的 Drive/Docs，`apps/api/src/app.together.db.test.ts`，以及网页测试）：每一步私密礼物都不改变收的人的 Doc、待写项、进度与问题记录；同一项不产生第二份当前 Doc，内容不变不写；汇总 2 分钟与 10 分钟的时机；页面只在历史版本形成后写；改名后崩溃不被当成 Google 里的修改；已删除页面不再写、不重建；页面不登记日记待写；对方接口看不到你的备份状态；Drive 里只有 Doc 与文件夹；用另一位用户已连接的 Google 账号连接被拒、不撤销。这里验的是真实 Google 的行为和人看到的样子。

## 最小检查（2026-11-18，通过）

Ray 用真实 Google 账号做了一次最小检查：建一个共享页面、两人各写一句；许一个愿；为对方准备一份礼物；几分钟后看两人的 Drive。结果：页面与心愿单都在两人的 Drive 里，作者颜色正确；收礼的一方看不到那份礼物。对应下表第 1、6、8 条的主要部分。改标题、删除页面、取消与揭晓、在 Google 改汇总、解绑与重绑、账号冲突、权限（第 2～5、7、9～18 条）未在真实 Google 上检查，只有自动测试覆盖。

## 准备

1. 用包含两个 PR（服务端、网页）的分支，`npm ci`；`.env` 按 `apps/api/README.md` 的"Setting up Google Drive"配好真实 Google 客户端、`GOOGLE_TOKEN_KEY`。
2. `npm run db:up`，`npm run db:migrate`（迁移 `0014`）。
3. `npm run dev:oidc`、`npm run dev:api`、`npm run dev:web`、`npm run dev:worker` 各开一个终端。
4. 两个浏览器配置，用开发登录分别登录 A、B（名字用 ASCII，开发登录会去掉非 ASCII 字符）；绑定。
5. A、B 各用**自己的** Google 账号在备份页连接 Drive；另准备第三个浏览器配置，用于第 17 条。
