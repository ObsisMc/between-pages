# 可安装的 PWA：iPhone 真机清单

日期：2026-11-18 写好清单。**状态：第 0 步（第 1、2 项）已在 2026-11-18 通过，其余待做，由 Ray 在真 iPhone 上做。** 本文是[可安装的 PWA ADR](../adr/2026-11-18-installable-pwa.md) D7 的真机清单。落地顺序第 0 步（第 1、2 项）应在合并第 1 个 PR 之前做；第 7 项要等第 2 个 PR 合并并部署以后，因为开发环境没有 HTTPS，主屏幕应用拿不到通知权限与角标。

自动测试已覆盖、这里不再重复的：Cache Storage 里只有页面文件与字体、离线打开显示离线页并在联网后自动进入、在线时断网出现全站提示、新版本出现"有新版本 · 刷新"且点后保留没发出的字（`e2e/pwa/pwa.e2e.ts`，桌面 Chromium）；角标的数字与清除（jsdom）。Playwright 模拟不了 iPhone 主屏幕应用，这里验的是 iPhone 本身的行为。
