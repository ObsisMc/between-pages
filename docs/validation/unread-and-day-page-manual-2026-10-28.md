1. `npm run db:up`，`npm run dev:oidc`、`npm run dev:api`、`npm run dev:web` 各开一个终端。
2. 两个浏览器窗口（或两台设备）分别用"开发登录"登录 A、B；A 生成邀请，B 接受（"暂不设置"），A 的范围为默认的全部日期。
3. A 写今天，写两三行中文；B 在首页点今天的卡片进入日期页，点"写这天"，写一行。
4. 每种浏览器都由 B 在日期页上操作，A 停在自己的单篇页观察。
