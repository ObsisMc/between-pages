示意图探索了用展开书页区分两人的心愿、用头像标明作者，以及用一条细小的未读提示跳到下一处新内容。手机端是一张可纵向滚动的书页，书签留在屏内。准备中的礼物与礼物墙有独立入口；礼物墙只展示已揭晓的礼物。

实现时仍应遵守已采纳的规则：心愿文字只由许愿的人修改；商品图片只来自可用的链接预览，未填链接时不补插画或附件；准备中的礼物、卡片及其计数只对送的人可见，收的人看到的自己的心愿单不因对方准备礼物而变化；未读在条目实际可见约一秒后才算已读。具体表现需在交互设计中继续验证。

**图片状态**：有链接且能取得预览图片地址时，浏览器直接从原网站加载该图，应用只保存预览文字和图片地址，不保存图片文件。无链接、抓不到图片或图片失效时，心愿与礼物墙都使用纯文字排版，保留名称、备注／卡片及适用的元数据；不出现空白图片框。示意图中的 `muji.com` 等网站与照片仅用于演示链接预览，不代表已经接入这些商品。
