## 页面与入口

- 「见面计划」有按月日历：确切见面画日期范围实线，大概月份／月份范围画月份虚线，未定日期的见面留在列表中；纪念日和整数日用另一种标记。选中一个日期后显示当天条目，并进入对应的见面或纪念日详情。
- 「纪念日」有自己的列表与详情：管理生日、在一起的日子和其他纪念日，查看倒数／第 N 天、历年同一天、相关礼物与日期页。月历是跨功能的浏览入口，不代替纪念日列表。
- 日期页和日记正文不是月历的默认内容；只有用户点「这一天的日记」才进入对应日期，避免在公开视野里暴露正文。

## 选日期的建议

- 新建纪念日先选种类。生日选归属、月、日，出生年份可选；在一起的日子与其他纪念日需要完整年月日。历史年份跨度大，年月日字段应能直接输入或跳选，不能只靠逐月翻日历。显示「每年重复」的预览。2 月 29 日按现有规则在平年落到 2 月 28 日。
- 计划见面先选「确切日期 / 大概月份 / 还没定」。确切日期用开始与结束两个日期字段，日历可辅助点选连续范围；大概月份用年月或起止月份，不能伪造某一天；还没定时无需日期。后续可从一种精度改成另一种。
- 纪念日提前提醒是每个人自己的设置。另一人的生日默认提前 7 天，自己的生日默认只在当天；图中的「TA 的生日 · 7 天」符合默认值。
- 日期是日历日期，不随时区换算；倒数和「今天」依查看者当地日期计算。

手机端建议使用单页月历，下方直接列所选日期的条目；日期选择器展开在书页内或从底部弹出，书签始终留在屏幕内。日历和条目区域可以纵向滚动，避免把桌面双页压成过窄两栏。
