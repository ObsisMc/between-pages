# 项目主旨与品牌

日期：2026-10-24。状态：名称和 slogan 暂定，后续可改名。

## 名字

**Between Pages**

GitHub 仓库名：`between-pages`。

这个名字让人想到书页之间的位置：文字可以在彼此的文字之间接续，两个人也在各自生活的间隙留下回应。这是项目赋予名字的意象，不引用特定典故。

## Slogan

**各自生活，在同一页相遇。**

英文版本：*Live your days. Meet on the page.*

GitHub 简介：A shared journal for two. Live your days. Meet on the page.

## 主旨

为两个人留一个共同书写的地方，让各自生活中的小事、想法与回应自然交织，慢慢成为共同的记忆。

## 产品原则

- 随时能写，也允许不写。不把陪伴变成打卡或回复考核。
- 两人都拥有表达空间。文字可以穿插，作者归属清楚，不替对方改写。
- 未读容易找到，阅读保持安静，不默认公开对方已读状态。
- 保存状态可信，合法输入不被旧状态静默抹去。
- 记忆能够带走。既能独立阅读，也有完整恢复路径。

## 气质

温暖、简约，有少量可爱的生活元素。界面以书写和阅读为中心；书、猫、植物等视觉元素以后按统一场景设计，不影响当前协同功能的技术验证。

品牌命名暂定，不影响稳定的用户身份、日记 ID、正文格式和备份版本。未来改名时更新展示、仓库及相关链接，不迁移或重写用户的文字归属。
